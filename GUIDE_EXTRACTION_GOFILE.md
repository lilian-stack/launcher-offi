# Guide d'extraction Gofile

## Ce qui se passe pendant le téléchargement :

1. **Téléchargement** : Le fichier .rar est téléchargé dans votre dossier
2. **Extraction** : Le contenu est automatiquement extrait
3. **Suppression** : Le fichier .rar est supprimé (normal)
4. **Détection** : Le jeu est automatiquement détecté et ajouté à votre bibliothèque

## Pourquoi vous ne voyez pas le fichier .rar :

- Les fichiers .rar sont **automatiquement supprimés** après extraction
- C'est **normal** et **voulu** pour économiser l'espace disque
- Les **fichiers extraits** sont conservés dans votre dossier

## Comment vérifier que l'extraction a fonctionné :

1. Regardez dans le dossier de téléchargement
2. Cherchez un nouveau dossier avec le nom du jeu
3. Vérifiez votre bibliothèque de jeux - le jeu devrait apparaître automatiquement
4. Les boutons "Lancer", "Ouvrir dossier", etc. devraient être disponibles

## Si le jeu n'apparaît pas automatiquement :

1. Redémarrez le launcher
2. Allez dans Paramètres > Scanner les jeux installés
3. Ou ajoutez manuellement le jeu depuis le dossier d'installation

## Dossiers recommandés :

- **C:\Games** (recommandé)
- **C:\Program Files\Games**
- Évitez les dossiers système comme Documents, Music, etc.
